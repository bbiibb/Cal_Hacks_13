# Cal_Hacks_13

A patient-education website that shows 3D human organs and surgical procedures step by step (Cal Hacks 13).

- First demo procedure: TAVR (transcatheter aortic valve replacement)
- Parts: frontend (`apps/frontend`: header, walkthrough list, 3D viewer), Convex backend (`packages/backend`), and a shared contract (`packages/shared`, zod schemas)
- Run the website: `pnpm install` then `pnpm dev:frontend`

> All content is educational dummy data and is not medical advice.

- Repository structure, branches, and ownership: [docs/github-structure.md](docs/github-structure.md)
